# DP Research Roadmap v3

A self-contained static website for the 45-day DP monograph roadmap.

## What is included
- Full 45-block roadmap with chapter/section references
- Study objective, checkpoint, self-test and coding task per block
- Complete monograph architecture
- Chapter-level navigation and final outcomes
- Four-pass study method
- Prerequisites-on-demand strategy
- Daily 6–7 hour structure
- Proof troubleshooting framework
- Concept and proof mastery levels
- Difficulty map
- Local progress tracking + JSON export/import

## Run
Open `index.html` directly, or deploy the folder to GitHub Pages.
