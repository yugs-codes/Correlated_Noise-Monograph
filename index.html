03

How to study this monograph

This is the part you should follow every day—not optional advice.

🎯 Monograph-first, prerequisites-on-demand

Do not spend weeks completing ML/probability/DP courses before starting. Read the monograph first. When a line genuinely blocks you:

  1. Identify the exact missing concept.
  2. Repair only that concept (typically 30–120 minutes).
  3. Work through one tiny example.
  4. Return to the exact line immediately.

Examples: covariance matrices, matrix norms, triangular/Toeplitz matrices, convexity, privacy amplification, stochastic optimization.

🔄 The four-pass method for important sections
Pass 1 · Narrative

What problem existed? Why is it difficult? What is introduced? What is achieved?

Pass 2 · Mathematical

For every equation: source, symbols, type (definition/transformation/inequality), and previous fact used.

Pass 3 · Reconstruction

Close the PDF: Definitions → assumptions → transformation → lemma → conclusion.

Pass 4 · Research

Why this formulation? What assumptions are restrictive? What breaks if changed? Is it practical? Could another structure work?

⏱ A realistic 6–7 hour study day
90 minNew material / narrative
120 minDeep mathematics & derivation
90 minProof reconstruction OR prerequisite repair
60 minTiny example / exercises / coding
45–60 minActive recall + notes + checkpoint

Never spend seven straight hours passively reading.

🧱 How to handle a proof that takes days

Do not bulldoze through it. Classify the blockage:

  • Type A — Missing definition: learn definition + one example.
  • Type B — Missing tool: repair exact linear algebra/probability fact.
  • Type C — Algebra gap: write every intermediate line.
  • Type D — Strategy gap: identify assumptions → target → intermediate lemmas → high-level strategy.
  • Type E — Genuine difficulty: record current proof level and revisit later. Hard proofs are not evidence of low ability.
📐 How to work through derivations

Never stare at an equation hoping it becomes intuitive. On paper write:

GIVEN:
WANT:
KNOWN FACT:
TRANSFORMATION:
WHY VALID:

For each proof line ask: What changed? Which property was used? Why is that property applicable?

🧠 Mastery & proof levels

Concept mastery: L1 recognize → L2 define → L3 why it exists → L4 use in derivation → L5 explain without notes → L6 implement → L7 question assumptions.

Proof mastery: P0 seen → P1 statement → P2 intuition → P3 architecture → P4 guided reconstruction → P5 independent reconstruction → P6 research fluency.

45-day target: Core concepts L5; major derivations L4–L5; core mechanisms L5–L6; advanced technical proofs P2–P3; central results P4–P5.
